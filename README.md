# Марта — личный секретарь в Telegram

Марта принимает текст и голосовые, понимает смысл с помощью GigaChat, раскладывает записи по
категориям и напоминает о делах. Утром в 9:00 присылает план на день, вечером в 23:00 — итог.

**Версия 1:** дела, платежи, дни рождения, заметки и идеи, список покупок, напоминания,
вопросы о планах («во сколько у меня завтра врач?»), обучение категориям на исправлениях.

**Мини-приложение:** тот же бот на удобном экране внутри Telegram — сегодня и ближайшие дни,
календарь, платежи с суммами, идеи и рекомендации со ссылками, покупки, поиск и настройки.
Открывается кнопкой «Марта» слева от поля ввода. Адрес: https://marta.ostepanovva.ru

## Как устроено

| Часть | Технология |
| --- | --- |
| Бот | Python 3.12, aiogram 3 |
| Понимание смысла | GigaChat API (модуль `marta/ai.py`, можно заменить) |
| Распознавание голоса | faster-whisper прямо на сервере, аудио никуда не уходит |
| База данных | SQLite, файл `data/marta.db` |
| Напоминания и сводки | APScheduler |
| Мини-приложение | aiohttp (уже есть в aiogram) + HTML/CSS/JS без сборки, `marta/webapp.py`, `marta/static/` |
| Запуск | Docker Compose |

Марта отвечает только владельцу (`OWNER_ID`), остальных игнорирует. Токены и ключи хранятся
только в файле `.env` на сервере и не попадают в GitHub.

## Установка на сервер

```bash
cd /opt && git clone https://github.com/ostepanovva/marta.git
bash /opt/marta/install.sh
```

Установщик спросит токен бота и ключ GigaChat, сохранит их в `/opt/marta/.env`
(доступен только root), соберет и запустит Марту.

## Мини-приложение

Работает в той же программе, что и бот, и пользуется той же логикой и базой. Каждый запрос
подписан Telegram (initData) и проверяется: данные получает только `OWNER_ID`.

Установка (один раз, из папки `/opt/marta`, после записи DNS `marta` → IP сервера):

```bash
sudo git fetch origin && sudo git checkout dev && sudo bash deploy/install-webapp.sh
```

Скрипт делает копию базы в `backups/`, включает приложение в `.env`, получает сертификат,
ставит отдельный файл Nginx (с проверкой `nginx -t`) и перезапускает Марту.

Выключить только приложение: в `.env` поставить `WEBAPP_ENABLED=0` и выполнить
`sudo docker compose up -d`. Полный откат к ветке `main`: `sudo bash deploy/rollback.sh`
(с `--nginx` — еще и убрать адрес из Nginx).

## Полезные команды (из папки `/opt/marta`)

| Что сделать | Команда |
| --- | --- |
| Посмотреть журнал | `docker compose logs --tail 100` |
| Перезапустить | `docker compose restart` |
| Обновить до новой версии | `git pull && docker compose up -d --build` |
| Остановить | `docker compose down` |
